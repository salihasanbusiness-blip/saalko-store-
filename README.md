# SAALKOO STORE — Concept Preview V1.1

Next.js 15 / React 19 / TypeScript bilingual (EN/BG) concept storefront.

## Start

```bash
npm install
npm run dev
```

## Included
- Responsive collection landing page and 4 concept merchandise mockups
- EN/BG switcher
- Cart quantity controls, persisted in browser localStorage
- Escape-to-close cart dialog and basic accessibility labels
- Disabled checkout and clear concept/preorder disclaimer

## Not yet implemented
Real product photography, sizes/variants, inventory, fulfillment, payment processing, privacy/terms/returns pages, order confirmation, automated tests, production deployment. **Do not accept payments or preorders yet.**

## Validation
Run `npm install && npm run build` and inspect on mobile and desktop. No successful build or live deployment is claimed by this package.
